My Learning Journey

I believe cybersecurity is a field that requires continuous learning and practical experience. This page presents the areas I am studying and practicing.

Cybersecurity Fundamentals

CIA Triad

Learning the three basic security goals: confidentiality, integrity, and availability.

Threats & Vulnerabilities

Studying threats, vulnerabilities, risks, attacks, CVE, and CWE to understand how security weaknesses are identified.

Malware

Learning about common malware categories, including viruses, worms, trojans, ransomware, spyware, and other malicious software.

DoS & DDoS

Understanding how denial-of-service attacks affect availability and how defensive measures can reduce their impact.

Networking

OSI & TCP/IP Models

Learning how network communication is organized through the OSI and TCP/IP models.

IP Addressing & Subnetting

Practicing IPv4 addressing, subnetting, CIDR, IP classes, and basic subnet calculations.

Network Protocols

Studying important protocols including HTTP, HTTPS, DNS, FTP, TCP, UDP, ARP, and SMB.

Network Security

Learning about NAT, VPNs, proxies, Tor, firewalls, IDS, IPS, and basic network defense strategies.

Linux & Command Line

Linux File System

Studying important Linux directories such as /bin, /etc, /home, /var, /usr, and /tmp.

File Management

Practicing commands such as ls, cd, pwd, cp, mv, rm, touch, and tree.

Permissions & Ownership

Practicing chmod, chown, and chgrp to understand Linux access control.

Logs & Analysis

Learning to examine files under /var/log and use commands such as cat, less, tail, and grep to analyze events.

Security Analysis

Wireshark

Practicing network packet capture and analysis to understand communication and identify suspicious network activity.

Log Analysis

Learning how security logs can be filtered and analyzed to identify failed attempts, errors, warnings, and unusual activity.

IDS & IPS

Studying intrusion detection and prevention, including signature-based and anomaly-based detection.

Incident Response

Learning the basic process of identifying, containing, investigating, and responding to security incidents.

Practical Learning Platforms

TryHackMe

Practicing cybersecurity concepts through guided rooms and hands-on laboratories.

Hack The Box

Developing practical security and penetration-testing skills through authorized challenges.

OverTheWire

Practicing Linux commands, command-line skills, and security problem solving.

My Current Focus

My current focus is strengthening my practical cybersecurity skills by combining theory with hands-on laboratories and projects.

I am working toward becoming a highly capable cybersecurity engineer with strong knowledge of networks, Linux, security testing, monitoring, analysis, and defensive security.
