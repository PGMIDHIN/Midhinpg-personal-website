Cybersecurity Learning

My learning focuses on understanding cybersecurity from both the offensive and defensive perspectives.

Learning networking fundamentals, IP addressing, subnetting, DNS, TCP/IP, OSI model, ports, protocols, firewalls, IDS, IPS, VPNs, and network traffic analysis.

Ethical Hacking

Developing practical knowledge of penetration testing, reconnaissance, vulnerability discovery, scanning, enumeration, and security testing.

Web Security

Learning how websites work and studying common web security concepts, vulnerabilities, authentication, input validation, and secure web development practices.

Linux & Security

Practicing Linux commands, file systems, permissions, ownership, logs, networking, shell scripting, and security-related administration tasks.

Security Operations

Learning log analysis, incident response, threat detection, network monitoring, security alerts, and defensive security techniques.

Practical Cybersecurity

Applying concepts through cybersecurity labs, Capture the Flag challenges, practical exercises, and security-focused projects.
